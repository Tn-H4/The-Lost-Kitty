# Game description
The Lost Kitty is designed for single-player use on a computer, with smooth keyboard controls and eye-catching UI. Though simple in presentation, it is a heartfelt project made for friends who enjoy classic arcade-style games. With its cute and charming theme and accessible gameplay, we hope whoever tries this game enjoys our fun project.  
  
Here is our [report](https://docs.google.com/document/d/1mShCWNzRQ5rRJzHPbeei_z2IXwL4mz4F7HgCeV6znHs/edit?tab=t.0).
